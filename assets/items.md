# 物品

`MISC.VFS` 的 `ITEM.DAT` 記載遊戲的全部物品——武器、防具、道具與轉職用品同在一張表，用 `TY` 欄位區分。record 佈局見 [`tables/items.md`](tables/items.md)。

## 來源

數值全部出自 `ITEM.DAT` 的實際 byte。名稱出自遊戲內文字：物品 `n` 的名稱是全域文字區塊 `FDETXT00.TXT` 的第 `0xC9 + n` 條（見 [`text/global_text.md`](text/global_text.md)）。

攻略站的裝備列表頁（鏡像在 [`docs/guide/`](../docs/guide/_index.md)）列的 226 個編號與資料檔有內容的範圍剛好一致，名稱與遊戲內文字逐筆比對後只有三處不同：

| 編號 | 遊戲內文字 | 攻略站 |
| ---: | --- | --- |
| `50` | 火神砲 | 光神砲 |
| `CC` | （空字串，遊戲裡顯示成空白） | 空白道具（章節攻略寫「空白Bug道具」） |
| `D5` | 空之寶石 | 空之魔石 |

攻略站列出的 226 個物品的 AP／HIT／DP／EV、附加屬性、距離修正，以及所有數量記在 record 裡的使用效果，全部與資料檔逐筆比對過，只有一處不符：**`4A` 風神弓的 HIT 攻略站寫 100，資料檔是 150**，以資料檔為準。攻略站有給幅度、record 裡卻沒有欄位的那些效果比對不了，列在下一節。

## 表的邊界

有內容的只有 `00`–`E1` 這 226 個編號，尾端的 `E2`–`FA` 是全 0 的空白 record。攻略站另外列出的「`FF` 裂地術／BUG 物品，價格和作用隨時變化」不是表裡的一筆——`FF` 已經超出 `ITEM.DAT` 的尾端（record 數見 [`resource_info/data_tables.md`](../resource_info/data_tables.md)），取到的是表尾之外的記憶體；「裂地術」這個名字同樣是越界讀來的，見 [`text/global_text.md`](text/global_text.md)。

表尾的空白 record 與沒有名稱的格子見 [`cut_content/items.md`](../cut_content/items.md) 的 I08；物品 `FF` 來自 `MAP09.DAT` 一筆填錯的死亡掉落，見 [`cut_content/_index.md`](../cut_content/_index.md) 排除清單的 I07。

## 沒有記在表裡的效果

record 的 23 個 byte 描述不了物品的全部行為，下面兩類效果在裡面找不到欄位，數值寫在程式裡：

- **每回合回復 MP**：我方階段開始時（`fdps_battle_advance_turn`，`0x1e3f0`，`src/btlturn.c`），**地圖單位 slot 4** 裝備著 `A6` 妖刀村正或 `A7` 妖刀正宗、**slot 8** 裝備著 `B1` 形見指環、以及**任何單位**只要帶著 `B3` 魔精石碎片，就回復 MP（向 `fdps_unit_restore_mp` 要 15，擲出 13 或 14，加上後以 MP 上限截頂；畫面浮出的是擲出的數字）。條件還有：狀態 byte 全為 0、MP 不等於上限。前兩項認的是 slot 而不是持有人——slot 4、8 是名冊第 5、9 位（裘娜、琴琴）固定坐的位置——換給別人裝備不會回復。只回復 MP，不回復 HP。攻略站把 `A6`、`A7` 寫成「HP+12～14/每回合」、把 `B1`、`B3` 寫成「MP+12～14/每回合」，與程式不符的是前者回復的其實是 MP，以及四件擲出的量都只有 13 或 14。
- **永久強化的幅度**：`D6` 生命之實 MHP +15、`D7` 魔力水晶 MMP +15、`D8`／`D9`／`DA` 三種藥水 AP／DP／DX 基礎值 +7、`DD` 風精之羽 MV +1、`A4` 強化套件 AP、DP 基礎值各 +30 與 MV +1、`AD` 強化套件 MHP +100。這幾件的使用效果碼有值（分別是 `0F`、`10`、`11`、`12`、`13`、`14`、`21`、`22`），但數量一律是 0——加多少是 `fdps_apply_item_effect_to_targets`（`0x262a0`，`src/item.c`）裡的常數，見下面的「使用效果代碼」。

反過來，消耗品的回復量是記在表裡的：`B4` 藥草 50、`B5` 回復劑 100、`B6` 再生藥 250、`B7` 魔法草 40、`B8` 魔法水 100、`B9` 水晶粒 250、`C2` 神聖之水 1000，七筆都與攻略站相符。

反過來，有幾件物品的 record 帶著使用效果，攻略站卻把它們當成沒有效果——攻略站的體例是「使用後無任何作用者不予列出」。`0C` 大地之劍是地系傷害 400（距 3 範 2），`22` 白銀之槍是冰系傷害 140（距 2 範 1），`0E` 精靈之劍的 `K1` 是 `0D`，`43` 封咒手套是 `1B`，`CC`（名稱空白）是 `05`，`D0` 光之水晶與 `D5` 空之寶石是 `06`。攻略站對 `05`、`06`、`0D`、`1B` 四個 `K1` 值的說明都是「不明」。

## 使用效果代碼

record `+0x0D` 的使用效果碼（攻略站稱 `K1`）怎麼被執行，出自 `fdps_apply_item_effect_to_targets`（`0x262a0`，`src/item.c`）與選目標的 `fdps_battle_item_menu`（`0x252b0`）。`數量` 指 record `+0x0E` 的使用數量；傷害與回復怎麼從數量擲出來見 [`program_info/spell.md`](../program_info/spell.md) 的「傷害公式」與「回復公式」。「帶這個碼的物品」由 [`tools/data_tables/`](../tools/data_tables/_index.md) 從 `ITEM.DAT` 產生並逐格驗證。
