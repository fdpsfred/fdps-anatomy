# 物品 record

`ITEM.DAT` 的一筆，23 byte，無對齊填充。數值見 [`assets/items.md`](../items.md)，檔案層面的事實見 [`resource_info/data_tables.md`](../../resource_info/data_tables.md)。

| 偏移 | 型別 | 欄位 | 內容 |
| ---: | --- | --- | --- |
| `0x00` | `u8` | `type` | 物品類型，見下 |
| `0x01` | `i16` | `ap` | 攻擊力增值 |
| `0x03` | `i16` | `hit` | 命中率增值 |
| `0x05` | `i16` | `dp` | 防禦力增值 |
| `0x07` | `i16` | `ev` | 速度增值 |
| `0x09` | `u8` | `hit_effect` | 攻擊附加屬性。`00` 無、`01` 麻痺、`02` 雙擊、`03` 暴擊、`04` 中毒 |
| `0x0A` | `u8` | `hit_effect_rate` | 附加屬性的發生機率（百分比）。雙擊不看這個欄位 |
| `0x0B` | `u8` | `range_min` | 攻擊距離最小值 |
| `0x0C` | `u8` | `range_max` | 攻擊距離最大值 |
| `0x0D` | `u8` | `use_effect` | 使用時的效果代碼，`00` 表示不可使用 |
| `0x0E` | `u16` | `use_amount` | 效果的數量（傷害量、回復量） |
| `0x10` | `u8` | `use_distance` | 施放距離。設了 `0x10` 這個位元表示直線，低 4 位是實際距離 |
| `0x11` | `u8` | `use_target` | 作用對象 |
| `0x12` | `u8` | `use_radius` | 影響範圍 |
| `0x13` | `u16` | `price` | 價格 |
| `0x15` | `u8` | `select_mode` | 使用時的目標選取模式，直接當作游標選取函式（`0x2b4f0`）的模式參數 |
| `0x16` | `u8` | — | 全表 251 筆一律為 0 |

## `type` 的取值

226 個有內容的物品用掉 40 個值，`0A`–`0C` 與 `14` 沒有用到：

- `01`–`09` 是攻略站列的武器分類（劍、刀、槍、杖、指環、拳套、弓，以及 `08`、`09` 兩種砲）。
- `0D`–`13` 與 `15` 是各只有一兩件的特殊武器（鐮刀、地獄之門、爪與牙、斧、靈擊、水晶球、武士刀、光束砲）。
- `16`–`27` 是防具，同一個系列（鎧甲、皮甲、袍、道服、裝甲）依強度再分成數個值。
- `28` 是道具，`29`–`2C` 是轉職徽章與劇情物品。

哪個編號屬於哪個 `type`，見 [`assets/items.md`](../items.md) 的全表。

## `use_effect` 的取值

攻略站列到 `20`，資料裡另有三個值只出現在特定物品上：`21`（習得轟神砲，`A4` 強化套件）、`22`（最大生命 +100，`AD` 強化套件）、`23`（`BB` 高能量裝置）。

## `select_mode` 只有五個值，選取函式只分辨三種

251 筆裡出現的只有 `0`、`1`、`3`、`4`、`5`，而且與 `use_effect` 的類別一致：傷害類是 `0`、回復與解狀態類是 `1`、永久強化類是 `3`、不可使用的物品是 `5`。`4` 只出現在 `0C` 大地之劍一筆上。

選取函式只認得三種行為：`5` 讓確認鍵完全不生效，`4` 讓游標下有單位就直接成立、跳過對象檢查，`0`／`1`／`3` 三者一律要通過同一道對象檢查，彼此沒有差別。也就是說寫進 record 的五個值裡，只有三種會表現出不同的選取行為。
