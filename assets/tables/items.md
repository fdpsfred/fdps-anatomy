# 物品 record

`ITEM.DAT` 的一筆，23 byte，無對齊填充。數值見 [`assets/items.md`](../items.md)，檔案層面的事實見 [`resource_info/data_tables.md`](../../resource_info/data_tables.md)。

| 偏移 | 型別 | 欄位 | 內容 |
| ---: | --- | --- | --- |
| `0x00` | `u8` | `type` | 物品類型，見下 |
| `0x01` | `i16` | `ap` | 攻擊力增值 |
| `0x03` | `i16` | `hit` | 命中率增值 |
| `0x05` | `i16` | `dp` | 防禦力增值 |
| `0x07` | `i16` | `ev` | 閃避增值（只加進單位的閃避 `ev`，不加 DX） |
| `0x09` | `u8` | `hit_effect` | 攻擊附加屬性。`00` 無、`01` 麻痺、`02` 雙擊、`03` 暴擊、`04` 中毒 |
| `0x0A` | `u8` | `hit_effect_rate` | 附加屬性的機率（百分比）：麻痺、中毒是另擲一次的發生機率，暴擊是加到職業暴擊率上。雙擊不看這個欄位 |
| `0x0B` | `u8` | `range_min` | 攻擊距離最小值 |
| `0x0C` | `u8` | `range_max` | 攻擊距離最大值 |
| `0x0D` | `u8` | `use_effect` | 使用時的效果代碼，`00` 表示不可使用 |
| `0x0E` | `i16` | `use_amount` | 效果的數量（傷害量、回復量） |
| `0x10` | `u8` | `use_distance` | 施放距離。`0x10` 以下是距離本身；`0x10` 以上表示直線，長度是值減去 `0x10` |
| `0x11` | `u8` | `use_target` | 作用對象 |
| `0x12` | `u8` | `use_radius` | 影響範圍 |
| `0x13` | `u16` | `price` | 價格 |
| `0x15` | `u8` | `select_mode` | 玩家使用時的選取模式：同時當目標收集的陣營篩選與游標選取函式（`0x2b4f0`）的確認模式，見下 |
| `0x16` | `u8` | — | 全表 251 筆一律為 0 |

## `type` 的取值

226 個有內容的物品用掉 40 個值，`0A`–`0C` 與 `14` 沒有用到：

- `01`–`09` 是攻略站列的武器分類（劍、刀、槍、杖、指環、拳套、弓，以及 `08`、`09` 兩種砲）。
- `0D`–`13` 與 `15` 是各只有一兩件的特殊武器（鐮刀、地獄之門、爪與牙、斧、靈擊、水晶球、武士刀、光束砲）。
- `16`–`27` 是防具，同一個系列（鎧甲、皮甲、袍、道服、裝甲）依強度再分成數個值。
- `28` 是道具，`29`–`2C` 是轉職徽章與劇情物品。

哪個編號屬於哪個 `type`，見 [`assets/items.md`](../items.md) 的全表。

## `use_effect` 的取值

攻略站列到 `20`，資料裡另有三個值只出現在特定物品上：`21`（`A4` 強化套件）、`22`（`AD` 強化套件）、`23`（`BB` 高能量裝置），效果見 [`assets/items.md`](../items.md) 的使用效果代碼。

## `select_mode` 只有五個值

251 筆裡出現的只有 `0`、`1`、`3`、`4`、`5`，空白 record 一律是 `0`。有使用效果的物品大致依效果分：傷害類與沒有分支的空殼碼（`01`–`09`、`0D`、`1B`、`1E`）是 `0`，回復、解狀態、`14` 風精之羽與 `21`–`23` 三件升級物品是 `1`，`0F`–`13` 五種永久強化是 `3`；例外是 `22` 白銀之槍（`09`）為 `5`、`0C` 大地之劍（`0A`）為 `4`，`4` 只有這一筆。沒有使用效果的 162 件裡 143 件是 `5`，18 件是 `0`，`BD` 魔神杖是 `3`。

玩家「使用」物品時（`fdps_battle_item_menu`，`0x252b0`），這個值同時送進兩處：`fdps_collect_targets_in_range`（`0x11e50`）拿它當陣營篩選，先收出瞄準時游標可切換的候選名單，確認後（施放距離不是直線時）再以同一個篩選收出命中名單；游標選取迴圈 `fdps_map_cursor_select_loop`（`0x2b4f0`）拿它當確認模式。確認鍵上 `5` 永遠不成立、只能取消；`4` 只要游標格在標出的範圍內就成立，不看格上有沒有單位；`0`／`1`／`3` 除了範圍之外，還要 `fdps_collect_targets_in_area`（`0x109f0`）以同一個值在游標畫出的範圍內找到至少一個它接受的單位——`0` 收陣營 0（敵方）、`1` 收陣營非 0（我方與 NPC）、`3` 只收陣營 2（我方），三者選得到的對象不同。`4`、`5` 在 `fdps_collect_targets_in_range` 裡一個單位都不收。直線物品的命中名單改由 `fdps_collect_targets_in_line`（`0x13670`）收，固定只收陣營 0，不看這個欄位。AI 不讀這個欄位，改看 `use_target`。兩支收集器的模式表見 [`program_info/map_ai.md` 的「目標收集」](../../program_info/map_ai.md#目標收集)，`4`、`5` 讓兩件武器在玩家手上用不出來的後果見 [`program_info/known_bugs.md`](../../program_info/known_bugs.md) 第 10 條。
