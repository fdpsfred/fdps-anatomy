# 25 — 知識庫翻新：補齊、刪減與未用、逐條驗證

**What to build:** 知識庫涵蓋 FDPS 的每個面向，而且每一條結論都對照實際情況驗證過。三件事：

1. **補齊知識庫內容**：以前作 FD2 的知識庫為參照，把 FDPS 缺少的文件補上——字模對照表、過場腳本／地形層／存檔格式、遊戲機制、全域文字、資料表、每章詳細資料（25.1–25.8、25.16）。
2. **刪減與未用**：把遊戲裡的殘留內容、空殼、被封住的內容、前作遺留（詞彙見 `CONTEXT.md`「刪減與未用」）逐條驗證後整理進新的頂層資料夾 `cut_content/`，圖存 PNG、音效與音樂存 WAV、文字全文照錄、程式痕跡逐條列（25.9–25.14），並修正調查中發現的既有錯誤（25.15）。
3. **逐條驗證**：知識庫的每一條結論（含本票新寫的）都被對照實際情況驗證過（25.17）。前作的教訓是知識庫會漂移——大量產出之後必然累積事實錯誤，寫過不等於寫對。

本票是總票，本身不做事，工作都在子票。

**前作參照來源**（依 CLAUDE.md，能沿用就沿用）：

- 文件範本：`fd2-anatomy/chapters/`、`assets/`（含 `tables/`、`text/`）、`resource_info/`、`program_info/`
- 工具：`fd2-anatomy/tools/decoders/`（文字與地圖事件解碼器）、`tools/glyph/`（字模像素比對）
- FDPS 端的資料來源：`src/`（已全部 emit，註解帶語意）、Ghidra、資源檔實際 byte、攻略站鏡像 `docs/guide/`

範本只借格式與涵蓋面，內容一律取自 FDPS 自己的來源；FDPS 與 FD2 結構不同之處（過場腳本、地圖編號 31 以上的額外場景、66 個文字區塊、`VFS` 容器）照 FDPS 的實際情況寫。

**Blocked by:** 各子票自己列；整組不等票 24（開發者已實機遊玩重建版前兩章，基本無問題）

**Status:** done（25.1–25.17 全部完成；執行期才答得了的問題在 `open_issues.md`）

**從這裡開始：** 本票是入口。先讀下方「跨子票的決定」與「共同要求」，再從子票表挑前置已完成的票做。一開始可並行的是 25.1–25.5 與 25.9；刪減與未用那條線的發現清單在 25.9。

## 跨子票的決定

- **重疊內容的擁有者**：
  - 原版 bug 的機制由 `program_info/known_bugs.md`（25.5）擁有；bug 造成的**被封住的內容**由 `cut_content/` 擁有並連過去，兩邊不重複寫。
  - 章節檔（25.8）列寶物、敵人時，拿不到或不出場的只寫一行並連到 `cut_content/`。
  - 「永遠不會顯示的文字頁」「永遠不會被載入的資源」由 `cut_content/` 擁有（25.13、25.14），`assets/text/` 與 `resource_info/` 不另列清單。
- **`cut_content/` 的素材**：PNG 與 SAF 內嵌的短音效 WAV 進版控（`.gitattributes` 標 binary）；CD 音軌轉成的 WAV 體積大，由工具從光碟映像重生、輸出目錄列入 gitignore，知識庫寫明怎麼重生。
- **字模**：前作是對倚天 `STDFONT.15` 逐像素比對反查 Big5；FDPS 照做。不完全吻合的字由開發者在網頁上逐字填入，不由 agent 猜（25.1）。

## 共同要求

依 `CLAUDE.md` 與 ADR-0007，每張子票都適用：

- 逐項工作由 workflow 全自動跑完，錯誤處理、續跑與收尾報告照 ADR-0007。
- 發現「重建時照直覺寫就會與原版不同」的事，當下寫進 `rebuild_info/pitfalls.md`。本票已知的候選（寫入前先確認是否已收錄）：
  - 第 28 章援軍以「回合 ÷ 2」算波次，第 7 回合截斷成 wave 3，wave 4 永不出場——「修好」會多出 3 名敵兵。
  - 第 26 章前的城鎮以章節索引減 1 查 24 列的暗號表，越界讀到堆疊——補一列就改變了遊戲。
  - 過場腳本 opcode `0x61` 的名字暗示除錯，實際是第 27 章隱藏路線的正式獎勵，不能當成除錯碼拿掉。
- 票內收斂不了、經開發者確認當下無法解決的問題才進 `open_issues.md`。
- 每張子票收尾時一起 commit：程式碼、知識庫、Ghidra 快照（有動 Ghidra 時）、一篇 devlog；workflow 的 agent 回報歸檔到 `devlog/runs/`。
