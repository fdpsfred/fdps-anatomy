# 03 — 攻略站抓取與解析

**What to build:** FDPS 攻略站的內容變成可程式化查詢的結構化資料。抓取與解析流程以遊戲代號參數化，因此同一套程式也能處理前作與一代的攻略站——這同時提供了驗證手段：先跑前作站台，拿前作知識庫已記錄的正確答案比對，確認解析器真的寫對了才用在 FDPS 上。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 9 個內容頁全部抓取並解析成結構化資料（裝備、法術、人物屬性、記憶體結構、程式修改、資訊修改、新手提示、章節攻略、密技）
- [ ] 抓取流程以遊戲代號參數化，切換代號即可處理前作站台
- [ ] 先對前作站台執行，解析結果與前作知識庫已記錄的數值逐項比對通過
- [ ] 正確處理 UTF-8 BOM，欄位值不含殘留的位元組順序標記
- [ ] 正確切分 `<pre>` 區塊內以全形空白對齊的等寬表格，中英文混排不會造成欄位錯位
- [ ] 內嵌的樣式標籤被剝除，且被用作區段分隔的錨點
- [ ] 抓取失敗或頁面結構改變時明確報錯，不靜默產生空資料
- [ ] 解析結果與抓取流程的說明進知識庫
