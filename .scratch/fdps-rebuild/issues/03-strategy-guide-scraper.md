# 03 — 攻略站鏡像

**What to build:** FDPS 攻略站的內容變成專案內可查詢的參考資料。抓取流程以遊戲代號參數化，因此同一套程式也能處理前作與一代的攻略站——這同時提供了驗證手段：跑前作站台，拿前作知識庫已記錄的正確答案抽查，確認鏡像沒有失真。

原訂的「解析成結構化資料」在實作中放棄，改為鏡像原文＋字串搜尋，理由見 ADR-0006。下方勾選項已按此調整。

**Blocked by:** None — can start immediately.
