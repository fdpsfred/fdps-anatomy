# 25.1 — 字模對照表與文字解碼器

**What to build:** `FDETXT.FON` 的每一個字模都對到一個確定的中文字，任何 `FDETXTnn.TXT` 都能解成可讀的文字，不再有 □。

做法照前作 `fd2-anatomy/tools/glyph/`（`render_glyph_atlas.py`、`et3_pixel_match.py`、`ET3_fonts/`）與 `fd2-anatomy/resource_info/chinese_glyph_encoding.md`：把字模抽出來，對倚天 `STDFONT.15` 逐像素比對，完全吻合的以 ET3 的字序反查 Big5。ET3 字序與標準 Big5 線性公式不同（無 `0xA1xx`–`0xA3xx` 符號區、`0xC6` 只有 63 字、倚天擴充字要用 cp950 解），前作文件有完整說明，照抄不重造。

不完全吻合的字**全部**做成一個網頁：每格顯示字模放大圖、最接近的幾個候選字與差異像素數，下方一個輸入框讓開發者打上正確的字；輸入要能被讀回，不靠開發者手動轉貼。開發者填完之後才補進對照表。
