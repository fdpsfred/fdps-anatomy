**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 容器 header 的欄位語意確認並記入知識庫，包含與前作格式的對應關係
- [ ] 每個 sprite 的解碼結果尺寸與 header 宣告的寬高一致
