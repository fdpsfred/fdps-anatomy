# 25.2 — 過場腳本格式與解碼器

**What to build:** 任何一支過場腳本都能被解成可讀的步驟列表，而且知識庫有一份過場腳本格式的正典文件。

涵蓋 `ICONnn`（開場）、`WINnn`（勝利）、`GOODEND`、`WINGA26`、`ICON7-x`、`WIN17-1` 等全部腳本：結構、每個 opcode 的長度與語意、切換地圖（`SWITCH_MAP`）、顯示文字、播放動畫與音樂、部署波次等指令，以及每支腳本由誰在什麼時機播放。語意的依據是 `src/icon.c` 的直譯器與它的呼叫端。

驗收的硬指標：解碼器照 opcode 長度走完每一支腳本，都必須剛好停在最後一個 byte 的結束指令上，沒有剩餘 byte。
