# 25.3 — 地圖與地形層格式

**What to build:** 知識庫能回答任何一張地圖的任何一格是什麼地形、能不能搜尋、會觸發什麼事件，以及每張地圖的回合事件、格子事件、部署記錄與寶物記錄的完整語意。

- 地形層格式新文件：`Mnn.DTL`（事件碼層）、`Mnnn.MPL`、`ATTRnnn.DAT`、`DSCnn.DAT` 的佈局與程式的讀法（`src/maptile.c`、`src/rsrc.c`）
- `resource_info/map.md` 擴充：可搜尋格的種類與屬性條件（`src/btlact.c`）、死亡腳本指令、AI 行為代碼（`src/mapai.c`）、回合事件的階段值、寶物記錄（`+0x53`）的種類與編號範圍、每張地圖的統計表

**Blocked by:** None — can start immediately

**前作參照：** `fd2-anatomy/resource_info/fdfield.md`（FD2 的 `FDFIELD.DAT` tile_event 區塊與 char_spawn 記錄）只借了涵蓋面——FD2 把地圖、事件、部署包在同一個 LLLLLL 檔裡，FDPS 拆成 `DTL`／`MPL`／`ATTR`／`DSC`／`MAP`／`COD` 六種檔，欄位也不同（FD2 的 `+0x15` 是 race 篩選，FDPS 是波次），內容全部取自 FDPS 的 `src/` 與實際 byte。`fd2-anatomy/tools/decoders/fdfield_*` 解的是 FD2 格式，不適用。

**逐項判定：** 本票沒有逐 function 或逐 data 符號的判定——代碼語意取自十支已 emit、註解齊全的 function，統計是整體資料的事實，都屬 CLAUDE.md 鐵則邊界外的整體調查，因此沒有 workflow。
