# 08 — 光碟盤點與 CD 音源範圍界定

**What to build:** 弄清楚遊戲音樂到底由誰播放，因為這決定了重建工作的邊界。執行檔內找不到紅皮書音軌控制的指令特徵，卻存在裝置請求失敗的錯誤訊息，以及指向光碟上外部程式與影音檔的路徑格式字串——音樂可能根本不由主程式負責。這個問題現在釐清，比在 emit 階段才發現便宜得多。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 兩片光碟掛載並盤點，內容清單（檔名、大小、SHA-256）進知識庫
- [ ] 光碟上的外部程式與影音檔的角色查明
- [ ] 從裝置請求失敗的錯誤訊息在 Ghidra 中反查參照者，追出實際的 CD 存取路徑
- [ ] 明確結論：音樂播放是否屬於本專案的重建範圍
- [ ] 若屬於範圍，該子系統的規模估計進知識庫；若不屬於，明確記錄為外部相依
- [ ] 遊戲啟動時的光碟檢查邏輯查明，確認自動化建置環境需要滿足什麼條件
