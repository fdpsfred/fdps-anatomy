# 25.7 — 資料表補齊

**What to build:** `assets/` 的數值表完整到可以只看知識庫就回答「這個單位、這件物品、這個職業是什麼」。

- `enemies.md`：`ENEMYDAT.DAT` 91 筆全表附名稱（取 `FDETXT00`，肖像編號 + 1）、出場數值公式、擊殺經驗公式
- `races.md`（新增）：種族代碼 ↔ 名稱與代表單位，並與部署記錄的波次欄區分
- `names.md`（新增）：角色譯名收斂（名表正名、對白變體、攻略站寫法）
- `characters.md`：補加入章節與條件、每人每職業的法術習得總表、轉職路線
- `classes.md`：補轉職物品與路線（`RANKUP.DAT`）；同步更正 `resource_info/data_tables.md` 的「尚未解讀」
- `items.md`：補使用效果代碼對照表；同步更新 `fdps-data` skill 的對應說明
- `tables/`：補 `RANKUP.DAT`、`SHOPnn.DAT` 的 record 結構

表中屬於刪減與未用的列（沒人用的職業、從未部署的敵兵、拿不到的物品等）只標一行並連到 `cut_content/`。
