# 25.6 — 全域文字與非章節文字區塊

**What to build:** 遊戲裡每一段不屬於某一章的文字都能在知識庫查到原文，並知道是誰在什麼時候讀它。

- `assets/text/global_text.md`：`FDETXT00` 全頁轉錄加語意分區（角色名、單位名、種族、職業、物品、法術、章名、勝敗條件、系統訊息），每區註明程式的讀取端。敵方單位的名稱規則是「肖像編號 + 1」那一條
- 非章節文字區塊 `FDETXT31`–`65` 的全頁轉錄，並寫明各由哪個場景（地圖編號、腳本）使用

永遠不會顯示的文字頁不在這裡列，歸 `cut_content/`（25.14）；這裡遇到時只標一句並連過去。

**Blocked by:** 25.1、25.2

**Status:** done

- [x] 轉錄一律由 25.1 的解碼器產生，不手打
- [x] 每個文字區塊標出使用它的地圖與腳本（取自 25.2 的對照）
- [x] `assets/text/_index.md` 更新

**前作來源：** `fd2-anatomy/assets/text/global_text.md`（名稱表以「欄位值 + 常數」定位、系統訊息分組列讀取端的頁面形式）與 `endgame_text.md`（非章節區塊獨立一頁）。只借形式；FD2 的全域文字含章名與勝敗條件，FDPS 的沒有——它們在各章自己的區塊開頭。

**產物：** `assets/text/global_text.md`、`assets/text/scene_text.md`，兩頁由 `tools/global_text/global_text.py build` 產生，`verify` 核對手寫分區與 `src/` 掃描、腳本追蹤一致並比對頁面是否過期。本票沒有逐項判定：讀取端是對 `src/` 的確定性掃描，哪條會顯示是腳本追蹤的確定性結果。
