# 25.6 — 全域文字與非章節文字區塊

**What to build:** 遊戲裡每一段不屬於某一章的文字都能在知識庫查到原文，並知道是誰在什麼時候讀它。

- `assets/text/global_text.md`：`FDETXT00` 全頁轉錄加語意分區（角色名、單位名、種族、職業、物品、法術、章名、勝敗條件、系統訊息），每區註明程式的讀取端。敵方單位的名稱規則是「肖像編號 + 1」那一條
- 非章節文字區塊 `FDETXT31`–`65` 的全頁轉錄，並寫明各由哪個場景（地圖編號、腳本）使用

永遠不會顯示的文字頁不在這裡列，歸 `cut_content/`（25.14）；這裡遇到時只標一句並連過去。
