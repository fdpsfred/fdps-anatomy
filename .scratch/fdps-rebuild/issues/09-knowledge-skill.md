# 09 — FDPS 遊戲資料查詢 skill

**What to build:** 累積的遊戲資料變成一個可查詢的 skill，後續在 Ghidra 裡看到一個數值時能直接問「這是什麼」，不用每次翻原始資料檔。

**Blocked by:** 03, 07

**Status:** ready-for-agent

- [ ] skill 涵蓋裝備、法術、人物屬性與成長、職業、章節資料
- [ ] 查詢介面能依名稱、代碼、數值範圍反查
- [ ] 資料來源明確標註是攻略站或實測 dump，兩者不一致時以實測為準並標明
- [ ] skill 的建置流程可重複執行，資料更新後能重新產生
